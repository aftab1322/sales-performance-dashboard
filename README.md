# Sales Performance Dashboard

## Overview
Interactive sales performance dashboard built using Power BI to analyze sales trends, performance metrics, products, regions, and business insights.

## Tools & Technologies
- Power BI
- Power Query
- DAX
- Excel / CSV
- Data Visualization

## Key Analysis
- Sales and performance trends
- Product performance
- Regional performance
- Key business metrics
- Interactive dashboard analysis

## Files
- `SALES DASHBOARD.pbix` — Power BI project file
- `SALES DASHBOARD.pdf` — Dashboard preview
- `Orders.csv` — Orders dataset
- `Details.csv` — Sales details dataset
